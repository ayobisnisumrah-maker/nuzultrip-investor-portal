# Profil Perusahaan

Modul `/admin/company-profile` adalah sumber data kanonik untuk profil perusahaan Nuzultrip.

## Blok data

- identity
- legal_information
- history
- vision
- mission
- leadership
- business_overview
- business_ecosystem
- strategic_direction
- milestones
- achievements
- statistics
- contact
- brand_assets

## Lifecycle

Draf → Ditinjau → Disetujui → Terbit.

Profil yang sudah terbit dapat memulai revisi baru tanpa mengubah snapshot terbit sampai versi pengganti diterbitkan.
