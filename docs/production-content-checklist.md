# Production Content Completion Checklist

This checklist is intentionally content-neutral. It tracks whether each Admin-controlled domain is connected to production data without inventing values.

- [ ] Company Profile: Admin-managed, published content rendered
- [ ] Portal Pages: published pages rendered
- [ ] Portal Sections: published sections rendered in configured order
- [ ] Data Room: accessible published documents rendered
- [ ] Financial Reports: published periods/reports rendered
- [ ] Financial KPIs: published KPIs rendered when available
- [ ] Ownership: investor-specific holdings rendered when available
- [ ] Profit Distribution: published distributions and allocations rendered when available
- [ ] Payment Proofs: authorized proofs rendered when available
- [ ] Messages: investor threads/messages rendered from production data
- [ ] Notifications: production notifications rendered
- [ ] Profile: authenticated investor profile rendered
- [ ] Empty states: used whenever Admin has not published content
- [ ] Loading states: no fabricated fallback values
- [ ] Error states: no fabricated fallback values
- [ ] Access control: RLS remains authoritative

No item on this checklist authorizes creation of dummy business data.
